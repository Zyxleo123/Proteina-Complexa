# LP → CP research plan

Planning snapshot: 17 September 2026. Repository reviewed: `Zyxleo123/Proteina-Complexa`, branch `cpsea`, commit `8d6ac02436ebf580f873e5d5c302f74b0404a6cf`. This is a proposed research plan; the new experiments and cluster inventory below have not been run.

**Recommended commitment.** First establish a useful constrained cyclization procedure on real linear peptide–receptor structures. Then learn to accelerate it. The shared research question is: **Can we find a low-loss cyclic sequence and conformation under a hard mutation budget while preserving selected atoms of an existing binding motif?** Start with bound structures for both tasks, using the same generator, data representation, and evaluator. Extending to an LP sequence without a known binding pose is a later task with an additional source of uncertainty.

For each budget of zero, one, or two substitutions, minimize the chosen loss over the permitted sequences and conformations. Report the best loss found at each budget. This does not claim that finite search finds the optimum over all mutation combinations, or that the smallest successful budget found is globally minimal.

**What to download.** The repository documents enough existing resources to attempt the first pilot without another large dataset or foundation-model download. Those references do not prove that files still exist on the cluster.

**Data roles and generalization.** CPSea supplies simulated cyclic geometries and receptor context. MEET supplies AFDB-derived linear fragments, and therefore cannot independently demonstrate transfer to experimentally observed LP binders. CPSea-PDB also contains computationally cyclized fragments; its name does not make those products experimentally determined cyclic complexes. [CPSea curation instructions](https://github.com/YZY010418/CPSea#dataset-curation), [MEET staging documentation](https://github.com/Zyxleo123/Proteina-Complexa/blob/8d6ac02436ebf580f873e5d5c302f74b0404a6cf/scripts/build_meet_metadata.py).

| Learning component | Input → supervision | What still requires validation |
|---|---|---|
| Motif-conditioned CP generator | Full CP examples with selected motif atoms revealed → their complete CP sequence and structure. Sample masks online. | Transfer from synthetic CP motifs to real LP motifs; physical feasibility of the requested constraints. |
| Mutation ranking/search model | Real LP sequence, receptor, motif, budget, and candidate mutation set → computed outcomes from the same search/evaluation procedure. | Ranking on unseen receptor families; robustness to scoring errors and stochastic generation. |
| Optional synthetic warm-start for mutation proposals | Perturb a known CP sequence within a budget → recover a known feasible CP solution. | These are reconstruction examples, not observed LP→CP conversions or globally optimal mutation labels. |

Keep all variants, alternate masks, and synthetic derivatives of the same parent in one split. Audit overlap by receptor sequence family, parent structure/accession, and peptide/interface similarity across LP, MEET, and CPSea sources. A different dataset name or PDB identifier is insufficient. Existing foundation-model pretraining overlap may be only partly auditable; report that limitation explicitly.

LNR has already influenced the repository's preprocessing and sampling decisions. Treat it as development data. Reserve fresh receptor families from a real LP collection before adapting models or tuning scores. If the available corpus cannot support a meaningful family-separated holdout, constrain the generalization claim or obtain additional experimental structures before expanding training.

**Stage 0 — verify the working system and measure its cost.** Use the existing cluster environment. Locate the CP checkpoint/AE pair, metadata, original LP structures, and scorer. Pin the repository revision and resolved configuration. Profile about 16 production-setting generations across small and large pockets, including intended guidance, plus a small CPU scoring batch. Record seconds per structure, peak GPU memory, CPU core-seconds, and output bytes. Use one 48 GB GPU as the initial planning target because current scripts target an A6000; measure actual requirements before scheduling.

Check exact decoded-sequence compliance, mutation counting, receptor-frame consistency, motif atom availability, and closure chemistry. Inspect CP autoencoder round-trip errors on the intended motif atoms: a poor reconstruction floor can limit downstream conditioning. A missing atom or an abstained chemistry must fail the corresponding metric. In particular, do not count a missing closure score as success.

Use the documented pocket crop as a starting point and verify contact coverage on the selected inputs. Preserve all contacting receptor chains; the current documentation identifies four LNR cases with discarded contacting chains. [Target preprocessing findings](https://github.com/Zyxleo123/Proteina-Complexa/blob/8d6ac02436ebf580f873e5d5c302f74b0404a6cf/docs/old_docs/README_TARGET_DISTRIBUTION_MATCHING.md).

**Stage 1 — search feasibility, with no new training.** Select 24 development complexes across peptide length, terminal separation, and whether the termini participate in binding. Start within the model's supported canonical amino acids and length range. Select one terminal cyclization chemistry after the preflight establishes reliable generation and scoring; keep that chemistry fixed across compared methods. Account for required anchor substitutions within the budget. A disulfide requiring two introduced cysteines consumes both substitutions at budget two.

Use one to three explicitly chosen functional residues per motif. Lock their identities and reveal the corresponding functional-group atoms. Keep this selection fixed across comparisons. Existing guidance provides a baseline for structural preservation; implementing an atom-specific guidance loss is a small first extension if the current losses are insufficient. The current graft experiments demonstrate that closure can coexist with substantial pose displacement, so closure alone is an inadequate gate. [Anchor-graft findings](https://github.com/Zyxleo123/Proteina-Complexa/blob/8d6ac02436ebf580f873e5d5c302f74b0404a6cf/docs/old_docs/README_ANCHOR_GRAFT.md).

Compare three arms using the same generator and scoring protocol: the unchanged LP sequence; chemistry-compatible random mutation combinations; and a simple score-guided search over compatible mutation combinations. Both mutation arms respect the same protected positions and hard budget. The unchanged-sequence arm measures the gain from allowing edits; the two mutation arms compare proposal quality.

An illustrative maximum is 24 cases × 3 arms × 16 generated conformations = 1,152 structures. For each mutation arm, this could be eight candidate combinations with two conformations each. Re-evaluate the two selected finalists per case with four fresh conformations each: 192 additional structures. Together with the preflight, the ceiling is approximately 1,360 outputs. Reuse candidates across budget summaries according to their actual substitution count.

Start with a cap of **24 GPU-hours and 300 CPU core-hours** for this feasibility tranche. These are proposed spending limits, not runtime predictions. If profiling indicates the ceiling above will exceed either cap, reduce the candidate count equally across compared arms before launching. Prefer retaining case diversity. Choose one production sampler setting; a large noise/guidance/grid sweep is outside this tranche. Use fewer-step screening only after checking that it preserves useful rankings against the production sampler.

GPU-hours are estimated as the number of generated structures multiplied by measured GPU-seconds per structure, divided by 3,600, plus measured setup overhead. CPU core-hours use the corresponding measured core-seconds. Parallel workers shorten elapsed time but do not remove the total compute cost.

**Define success before examining new search results.** A candidate must simultaneously satisfy the decoded mutation budget and protected identities, requested cyclic connectivity with plausible bond geometry, acceptable all-atom stereochemistry and clashes, and motif preservation relative to the receptor. Align the receptor when computing motif displacement; independently aligning the motif would conceal movement away from its binding site. Report both mean motif displacement and worst-atom displacement.

Select and record numerical geometry tolerances using the preflight and reference structures. A reasonable starting engineering target is motif RMSD no greater than 0.5 Å and worst-atom displacement no greater than 1 Å, subject to measured reconstruction and structure quality. These are proposed tolerances, not validated biological thresholds. If coordinates must be exactly fixed, use explicit equality constraints during final all-atom refinement, then check the resulting chemistry and strain. Coordinate overwriting alone is not a valid repair.

Use interface energy and peptide strain as separate quantities under a fixed evaluation protocol. The native LP provides context, but LP and CP raw total energies are not automatically thermodynamically comparable. Keep sequence length and chemistry consistent when making primary score comparisons. Report success per case, success per attempt, best valid loss under a fixed budget, and total compute. Treat receptor families as the independent units for uncertainty estimates. A favorable computed energy is not a measured binding affinity.

**Gate after Stage 1.** Continue toward learned mutation search only if useful candidates recur across several distinct receptor families, survive fresh samples and independent rescoring, and show improvement over a simple proposal baseline. An isolated favorable structure does not meet this gate. If closure succeeds but motifs drift, prioritize Stage 2. If sequence compliance fails, repair that interface first. If every strong constraint setting fails, test a small, declared relaxation of budget or motif tolerance to distinguish inadequate search/model coverage from an overly restrictive task. Failed finite search is not a proof of infeasibility.

**Stage 2 — learn motif-conditioned cyclization if it addresses the measured bottleneck.** Start with a cluster-diverse subset of the existing CPSea training split, approximately 5,000–20,000 parent complexes as an initial scale. Sample motif masks during loading. The data are complete CP structures; the motif is the observed condition, and the unobserved atoms remain part of the supervised output. No expensive LP→CP optimization labels are required for this stage.

Keep the matched CP autoencoder frozen. Warm-start the CP flow model, add indexed motif identity, coordinates, and observation-mask features while retaining receptor and cyclization conditioning, and train with the flow objective plus decoded motif/identity losses. The repository already contains an indexed motif feature configuration, but it is not directly interchangeable with the CP config: feature dimensions and pretrained-weight loading need explicit handling. [Indexed motif configuration](https://github.com/Zyxleo123/Proteina-Complexa/blob/8d6ac02436ebf580f873e5d5c302f74b0404a6cf/configs/nn/local_latents_score_nn_160M_idx_motif_tip.yaml).

Atom37 is an atom-slot representation. Use a separate mask for which atom positions are supplied as conditions; do not confuse that with which atoms exist for an amino-acid identity. Latent clamping cannot guarantee exact sidechain coordinates. Learned conditioning should improve the distribution of feasible proposals; explicit constrained refinement provides exact-coordinate enforcement when requested.

Start one warm-start training run with a further **24 GPU-hour cap**, evaluating early at the same sampling budget on held-out CP parents and the real LP development cases. Measure optimizer-step throughput before deciding the number of steps. Scale data or compute only if real LP joint success improves; synthetic reconstruction loss alone is insufficient. If the AE is the bottleneck, diagnose its coverage before committing to retraining it.

**Stage 3 — learn the mutation search only after the teacher works.** Generate a first batch on roughly 100–200 diverse real LP development/training complexes, expanding only when feasible solutions and informative comparisons appear across families. Save candidate mutation sets, decoded sequences, seeds, failures, constraint residuals, component scores, and compute cost. A mask expansion or multiple conformations of one parent does not count as additional independent tasks.

Fit a small candidate ranker or proposal model first. Train on comparisons among mutation combinations for the same LP context and budget, including interactions between mutations. Use the model to guide search and verify its proposals with the existing structural generator and scorer. This is cheaper to diagnose than a full reinforcement-learning pipeline, and it does not require pretending that the best sampled sequence is the unique optimum.

The useful result is a curve of valid solution quality against generator/scorer calls on unseen receptor families. Compare with chemistry-aware random proposals and the simple search from Stage 1 at matched compute. The learning system must save evaluation calls or improve outcomes at the same budget to justify its data-generation cost. Biological improvement ultimately needs independent experimental evidence, ideally including paired LP and designed CP measurements on selected targets.

**Resource discipline for the longer project.** Share one CP generator and one evaluator across both tasks. Cache parsed pockets and reusable reference features. Save endpoint structures and compact per-attempt records rather than every diffusion trajectory; retain selected traces only for diagnosis. Preserve all failure records, but reserve expensive relaxation/refolding for valid candidates and a sampled set of rejected controls. Compare finalists with a fixed, independent evaluation protocol, and keep score components available so a proposal model cannot hide failures inside one aggregate score.

Sequence-conditioned cyclization already has directly relevant prior work: MuCO generates CP conformations from a linear sequence through backbone generation, sidechain packing, and refinement. Its official implementation provides a later fixed-sequence baseline. The research emphasis here is mutation-budget optimization and preservation of a target-bound atomistic motif. A full novelty claim requires a focused comparison against current motif-scaffolding and constrained-design methods before finalizing the paper scope. [MuCO implementation](https://github.com/mianqiu00/MuCO).

**Immediate next action.** Run a read-only inventory and the small production-setting profile on the existing cluster environment. The first committed experimental deliverable is a table of joint feasibility, best valid loss, motif displacement, and compute by LP case and mutation budget. That table determines the next training investment.
